## Mövzu Xəritəsi

Bu workspace əsasən aşağıdakı OOP və C# mövzularını əhatə edir:

- Class və object model dizaynı
- Inheritance, polymorphism, abstract class
- Encapsulation və property validation
- Enum və status əsaslı axınlar
- Interface və service layer yanaşması
- Extension metodlar
- Custom exception-lar
- Constructor və static id artımı

## İstifadə Qaydası

1. İstədiyiniz bölmənin README faylını açın.
2. Şərtdəki entity, interface və servis tələblərini mərhələli implement edin.
3. Program.cs daxilində nümunə ssenarilərlə yoxlama aparın.

Qeyd: Bu workspace-də hazırda yalnız tapşırıq şərtləri (README faylları) mövcuddur.
